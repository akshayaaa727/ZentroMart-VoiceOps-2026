# ZentroMart – AI-Powered Voice Customer Support Agent

An AI customer support assistant for ZentroMart that answers customer queries using Retrieval-Augmented Generation (RAG), handles order verification, and supports ticket escalation.

## Features

- Knowledge-base retrieval using RAG.
- Context-aware customer support responses using a local LLM.
- Order lookup with customer verification.
- Support ticket creation and escalation.
- Voice input using Gnani Speech-to-Text.
- Voice responses using Gnani Text-to-Speech.
- Batch processing of customer audio files.

## Tech Stack

- Python 3.11
- Ollama with Llama 3.2 (3B)
- Gnani STT and TTS
- Pandas
- OpenAI-compatible API client
- Retrieval-Augmented Generation
